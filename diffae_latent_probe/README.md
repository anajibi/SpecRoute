# `diffae_latent_probe`

The code that used to live in this directory was archived to
`archive/diffae_latent_probe/` (superseded by `experiments/hdae`; see
`archive/diffae_latent_probe/ARCHIVED.md`).

Only generated/data artifacts remain here, left in place because they're
still referenced or simply weren't worth moving:

- `data/` — raw CelebA-HQ images and label files. Still the live raw-data
  source for `experiments/hdae/configs/*.yaml` (see
  `experiments/hdae/AGENDA.md` §5). **Do not delete or move without updating
  every config under `experiments/hdae/configs/`.**
- `outputs/`, `configs/outputs/` — old run artifacts from the archived code,
  unreferenced by anything active.
